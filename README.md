A tiny deterministic program that writes one line, 137 characters, that reads as the funniest honest error message an appliance could show to /output/entry.txt: "Error: Unbalanced load. Your hoodie formed a gang with the towels and is holding the drum hostage. I refuse to spin until they negotiate."

The appliance is a washing machine and the fault is real: an unbalanced load makes a machine genuinely refuse to spin, because spinning off-balance would shake it apart. The laugh comes out of the truth of that fault — the laundry has teamed up, the drum is held hostage, and the machine will not spin until they negotiate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
